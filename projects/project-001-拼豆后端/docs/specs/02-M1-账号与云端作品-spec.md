# Spec：M1 账号、云端作品与团队验证环境

> 状态：待用户审阅；仅在 M0 验收并获得 Go 后执行。
>
> 目标：验证注册用户是否愿意并能够安全地跨设备保存、查看和管理拼豆作品。

## 结论

M1 交付一套可被 PixoMosaic Web 调用的身份与私密作品能力，并先部署到邀请制团队验证环境。它不做社区和订单；只有团队验证通过且业务方批准，才讨论公开注册或 M2。

## 用户场景

1. 用户使用邮箱设置密码并完成邮箱验证，或使用 Google 登录。
2. 已登录用户从前端主动把本地作品保存到云端；默认私密。
3. 用户在另一设备登录后可查看、读取和继续使用自己的作品数据。
4. 用户可删除作品；作品立刻从前台隐藏，30 天后完成物理删除。
5. Admin 能处理账户、删除请求和异常事件；Staff 不默认浏览普通用户的私密作品。

## 范围

### 本次要做

- 邮箱密码注册、邮箱验证、登录、登出、忘记密码和安全重设密码。
- Google 登录与安全账号绑定规则。
- 用户资料、角色、条款/隐私版本同意记录。
- 每用户最多 50 个默认私密作品；保存完整约定数据和文件。
- 私有文件上传、读取授权、作品列表/详情、更新、删除与 30 天回收期。
- 后端导出资格检查、登录/上传/写入限速、异常事件记录和基础 Admin/Staff 审计。
- Docker 化团队验证环境：邀请/白名单注册、独立数据库/存储/邮件、健康检查、备份与日志。
- 后端 API 自动化测试与 PixoMosaic 前端联调记录。

### 本次不做

- 公开社区、公开作品 URL、帖子、点赞、收藏、关注、举报和违禁词。
- 材料包、按图计数、定制、支付、地址、物流和客服。
- App 客户端、离线跨设备同步、实时协作、分享链接或公共下载。
- 绕过邮箱验证或通过同步 Shopify 密码登录。

## 关键业务规则

| 规则 | 决定 |
| --- | --- |
| 登录 | 邮箱密码 + 邮箱验证/重设；保留 Google 登录 |
| 账号状态 | 未验证邮箱可完成验证流程，但不能保存云端作品；停用账号不能访问私密资源 |
| 作品数量 | 每位用户最多 50 个 `active` 私密作品；新建超限时返回明确可操作提示 |
| 保存内容 | 原图、展示图、缩略图、图纸格点 JSON、生成参数、色号统计、材料清单和导出文件引用 |
| 文件访问 | 原图、图纸 JSON、导出文件均为私有；通过鉴权短期访问；展示图也不因“私密作品”自动公开 |
| 删除 | 用户删除后立刻不可见，进入 30 天回收；到期删除文件和元数据，并保留最小审计证据 |
| 反滥用 | 后端参与导出资格、登录、注册、重设、上传、写入限制；前端离线计数仅为最佳努力 |
| 后台角色 | Admin 可管理敏感操作；Staff 仅获得分配的后续运营工作权限，M1 默认无批量查看私密作品权限 |

## 密码、身份与安全要求

- 密码至少 12 个字符，使用服务端现代自适应哈希保存；不保存或展示明文密码。
- 邮箱验证和密码重设令牌为一次性、限时、哈希存储；使用后立即失效。
- Google 登录不可静默占用同邮箱的既有本地账号；必须通过受控绑定或邮箱验证确认归属。
- 所有浏览器会话使用 HTTPS、`Secure`、`HttpOnly` Cookie；CORS 仅允许登记的前端域名，并要求携带凭据。
- 对登录、注册、重设、上传、下载授权、作品删除、角色变更和后台敏感读取生成请求 ID 与审计记录。
- 日志不得记录密码、验证码、会话令牌、完整地址、完整原图 URL 或未脱敏个人数据。

## 作品与文件规则

- `WorkDocument.schemaVersion=1` 是 M1 的读取基线；前端提交不符合版本/校验要求的数据必须被拒绝并返回可诊断错误码。
- 每作品默认最多 10 个源/展示相关图片，单文件最多 15 MiB，导出文件最多 20 MiB，附件合计最多 100 MiB；每用户对象存储软上限 2 GiB。
- 图片 MIME 类型、扩展名、实际文件特征和大小均需校验；拒绝可执行文件、SVG 脚本、伪造图片和超限文件。
- 上传通过短期授权完成，上传成功后由后端确认元数据并关联作品；没有关联成功的孤儿文件必须可被定期清理。
- 作品保存是“用户主动动作”；前端不能在用户未确认时自动上传原图或工作数据。

## API 与前端联调边界

- 所有业务接口遵循 M0 的 `/api/v1` 契约、统一错误对象、分页和请求 ID 规则。
- 前端负责把既定格式的图纸 JSON 和文件提交给 API；后端负责身份、归属、版本、限额、存储和可审计读取。
- 未登录导出：前端继续显示剩余次数；在联网时调用后端资格检查。断网时仍可按本地规则导出，但不能声称后端可完全阻止规避。
- 作品读取、保存、删除和错误处理须由前端使用 API 验证，不允许直接查看对象存储或借用 Payload Admin 接口。

## 团队验证环境

| 项目 | 要求 |
| --- | --- |
| 注册 | 仅邀请/白名单测试邮箱；不对公共互联网开放自助注册 |
| 数据 | 使用独立测试 PostgreSQL、存储桶、邮件配置和密钥；禁止复用生产用户数据 |
| 邮件 | 可发送至受控测试邮箱；所有邮件标题明显标识为测试环境 |
| 访问 | 仅团队成员和指定测试人员；后台角色按最小权限分配 |
| 清理 | 测试数据可整体销毁；不将真实订单、地址或敏感客户数据写入测试环境 |

## 验收标准

- 测试用户可完成邮箱注册、验证、密码登录、忘记/重设密码与 Google 登录的关键路径。
- A 用户不能读取、下载、修改或删除 B 用户的作品和文件；Admin/Staff 的权限边界被自动化测试覆盖。
- 用户能保存、查看、读取和删除不超过 50 个私密作品，完整数据项可追溯。
- 超限文件、错误文件类型、无效 JSON、越权请求和高频请求被拒绝并产生安全审计，不泄露敏感信息。
- 30 天回收和到期删除具备可测试的任务记录与可重试机制。
- 团队验证环境可用，完成至少一轮注册、跨设备读取、删除和后台审计演练；结果写入阶段验收记录。

## 进入 M2 的门禁

- M1 所有验收项通过，且没有未解决的私密文件、权限或删除高风险问题。
- 团队能清楚解释注册、删除、数据保留和异常处理；业务方决定是否进入社区验证。
- Privacy Policy、Terms of Service 与公开注册决策由业务方单独确认；未确认时保持邀请制。
