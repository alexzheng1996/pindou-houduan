# M2.1 内容中心与 SEO/GEO API

> 状态：M2.1-A（本机官方内容草稿后台）已实现并通过本机验收；其余内容继续待后续批准。与 `specs/03a-M2.1-官方内容中心与SEO-GEO-spec.md` 配套。

## 0. M2.1-A 已实现：仅后台草稿

本阶段仅开放给已验证且 active 的 `staff` / `admin` 会话；不提供公开页面、审核/发布、排期、SEO/sitemap、媒体上传、视频块、MCP 服务身份或前端改动。

| 接口 | 当前语义 |
| --- | --- |
| `GET /api/v1/admin/content/articles` | 返回最多 100 条、按更新时间倒序的草稿安全投影。 |
| `POST /api/v1/admin/content/articles` | 创建 `draft`；服务端生成 `articleId`、版本号、最小审计记录。要求可信 Origin 与 `Idempotency-Key`。 |
| `GET /api/v1/admin/content/articles/:id` | 读取一篇草稿。 |
| `PATCH /api/v1/admin/content/articles/:id` | 以 `expectedVersion` 更新草稿；冲突返回 409。要求可信 Origin 与 `Idempotency-Key`。 |

最小输入为 `section`、`articleType`、英文 `slug/title/excerpt`、Lexical 富文本 `body`、作者显示信息、1–20 个 HTTPS 来源，以及质量/SEO 建议字段。`guides` 仅接受 `tool_guide|faq`；`blog` 仅接受 `creative|product_tutorial|case_study|announcement`。正文上限 512 KiB，slug 全局唯一。

请求可省略 `status`，也可显式写 `draft`；任何 `status != draft`、`publishedAt` 或 `scheduledAt` 都返回 `409 CONTENT_STATE_INVALID`，不会静默降级为草稿。普通用户返回 `403 CONTENT_OPERATOR_REQUIRED`。Staff 进入 Payload Admin 仅能访问 Content 集合，不能读取用户、账户、会话、验证码或私密作品。

本机受控迁移：`20260826_042051_m21_content_drafts`。它创建 `articles`、`articles_source_list` 和仅元数据的 `article_media`；媒体上传与公开读取尚未开启。

## 1. 公开读取（M2.1-B 冻结，尚未实现）

公开读取无需会话，但仅以服务端在请求时计算的公开条件决定可见性：`status=published`、`publishedAt <= now`，且未被归档或下架。无法满足条件的 slug、草稿、审核中、退回修改、排期未到、`needs_update`、归档或下架，均统一返回 `404 CONTENT_NOT_FOUND`；不得用状态、权限差异或响应时间向匿名访问者透露其存在。

`indexable=false` 只影响爬虫收录与 sitemap，**不**改变已发布文章的公开读取资格；页面须输出 `noindex`。公开响应只含以下安全投影，字段缺失时以 `null` 或空数组表达，不以内部字段补齐：

- 标识与内容：`publicId`、`section`、`slug`、`articleType`、英文 `title`、`excerpt`、经受控渲染的 `body`、`tableOfContents`；
- 公开归属与时间：`authorType`、`authorDisplayName`、`reviewerDisplayName`、`publishedAt`、`updatedAt`；
- 公开媒体：已授权的 `coverMedia`、正文媒体安全投影与受控 `videoBlock`；
- SEO/分享：`seoTitle`、`metaDescription`、干净 `canonicalUrl`、`ogImage`、`twitterCard`、`indexable`、公开分享目标与页面可见的 JSON-LD 数据。

公开投影绝不包含文章内部 ID、草稿/审核版本、编辑备注、审核理由、来源内部信息、案例授权原文、用户邮箱/会话、私密 Work 或原图、对象存储键/私有 URL、媒体上传状态、服务身份、Token 或审计原始记录。

### `GET /api/v1/content/articles?section=guides|blog&cursor=...&limit=...`

`section` 必填且只能为 `guides` 或 `blog`。`limit` 可省略，默认值及最大值由实现固定；仅接受正整数。`cursor` 可省略；提供时必须为上一页同一 `section` 返回的服务端不透明游标，客户端不得构造、解析或跨 section 复用。

列表按 `publishedAt DESC, publicId DESC` 稳定排序。响应为安全投影数组及 `nextCursor`：有下一页时返回不透明字符串，无下一页时返回 `null`。重复游标、畸形/过期游标、`limit` 越界或不支持的查询参数均返回 `400 CONTENT_INPUT_INVALID`，不得静默改写查询；空列表返回 `200` 与空数组、`nextCursor=null`。列表不返回正文、目录、完整来源清单、审核信息或内部媒体信息。

### `GET /api/v1/content/articles/:slug`

`slug` 必须是已发布公开文章的全局唯一英文 slug；缺失、格式错误或不满足公开条件时统一返回 `404 CONTENT_NOT_FOUND`。详情返回完整公开安全投影、正文、目录、公开作者/审核人显示名、已授权媒体、受控视频块、SEO 公共投影和分享配置；不得返回编辑备注、来源内部信息、对象存储键、草稿版本或运营授权原文。

请求可带标准 UTM 查询参数用于归因，但任何公开详情及其 JSON-LD、Open Graph/Twitter 元数据输出的 `canonicalUrl` 必须是该文章不带查询串、片段或 UTM 的本站公开 URL。未知或业务查询参数返回 `400 CONTENT_INPUT_INVALID`；UTM 不得改变内容、公开资格或分享权限。

### `GET /api/v1/content/sitemap`

返回仅含干净 canonical URL 的可收录集合：`published`、已到公开时间且 `indexable=true` 的官方文章，以及仍为 `published` 的精选社区案例。取消精选、撤回、下架、归档或删除必须使对应 URL 从集合中移除；UTM、私密 URL 和对象存储 URL 永不进入 sitemap。实际部署可映射为站点根路径 `/sitemap.xml`。

## 2. 审核、发布与公开元数据（M2.1-B 冻结，尚未实现）

文章状态机固定为：`draft → in_review → scheduled → published → needs_update → archived`，并允许 `in_review → changes_requested → draft`。`scheduled` 仅在计划时间到达后才公开；`archived` 不公开、不进入导航或 sitemap。退回修改必须记录原因；任一内容修改后回到 `draft`，不得保留旧审核通过标记。

只有人工 Staff/Admin 后台会话可提交审核、退回、排期、发布或归档；服务端记录操作者、时间、版本和理由。发布前必须校验英文 title/description、稳定 slug、正文、canonical、分享图、作者/更新时间、媒体/版权和视频授权；不满足时返回 `CONTENT_SEO_INVALID`、`CONTENT_MEDIA_INVALID` 或 `CONTENT_VIDEO_NOT_ALLOWED`，不得部分发布。

已发布文章修改正文、canonical、`indexable`、分享图、公开视频授权或公开视频字段时，必须递增版本并进入 `needs_update`；在人工重新审核并再次发布前，旧公开版本不再作为当前公开内容返回。审核动作并发版本不匹配返回 `409 CONTENT_VERSION_CONFLICT`；不允许的动作、角色或前置状态返回 `409 CONTENT_STATE_INVALID`。

`canonicalUrl` 默认只允许本站相应 section/slug 的无查询公开 URL；外部 canonical 仅能由 Admin 明确批准并记录原因。SEO 公共投影须与页面可见内容一致：公开详情提供 `Article`、`BreadcrumbList` 与可见 FAQ 的 JSON-LD；信息完整且已授权的受控视频才提供 `VideoObject`。`noindex` 不能代替访问控制、下架或删除语义。

### 受控品牌视频与 sitemap 数据边界

视频块只能是结构化 `videoBlock`，第一版只接受 `youtube` 或 `tiktok`、`ownership=brand_owned`、经服务端校验的官方域名/视频 ID 与允许频道/账号。公开投影可含 `platform`、`videoId`、`title`、`summary`、`caption`、已授权的缩略图/时长/发布时间、`externalUrl` 与 `embedAllowed`；不接受或返回 iframe、任意 HTML、脚本、未校验来源或内部授权记录。前端只按 `platform` 使用固定播放器；嵌入不可用时正文和 `externalUrl` 仍可用。sitemap 数据源只能使用本节定义的可收录安全字段，不得从草稿、媒体存储或编辑器原始数据拼接 URL。

## 3. 后台内容接口

> M2.1-A 已实现草稿的无筛选读取、创建和更新；以下是后续审核/发布阶段的扩展草案。

### `GET /api/v1/admin/content/articles`

Staff/Admin 可按 `section`、`status`、作者、更新时间、`indexable` 和 `articleType` 分页筛选。列表只返回必要字段。

### `POST /api/v1/admin/content/articles`

创建后台草稿。服务端生成 `publicId`、版本号和审计记录；请求不能直接指定 `published`。

### `PATCH /api/v1/admin/content/articles/:id`

编辑草稿或受控更新已发布内容。改变正文、canonical、`indexable`、分享图、视频授权时必须增加版本并触发重新审核要求。

### `POST /api/v1/admin/content/articles/:id/review`

请求示例语义：

```json
{
  "decision": "approve|changes_requested|schedule|publish|archive",
  "reason": "英文正文和视频授权已核对",
  "expectedVersion": 3,
  "scheduledAt": null
}
```

只有后台人工会话可执行审核、排期、`publish` 或 `archive`；MCP 服务身份不能调用这些动作。输入格式、未知 decision、缺失/非法 `expectedVersion` 或不合规 `scheduledAt` 返回 `400 CONTENT_INPUT_INVALID`。

## 4. MCP 草稿接口

> 尚未实现；当前没有服务身份、Token 或 MCP 路由。

MCP 只映射到草稿能力，使用短期、最小 scope 的独立服务身份，不复用后台管理员 Token：

- `content_draft_create`
- `content_draft_update`
- `content_review_request`
- `content_public_link_list`（只读公开投影）

草稿最小输入包括 `section`、`slug`（可选）、`title`、`excerpt`、受控正文、`articleType`、来源清单和 SEO 建议。MCP 只能创建草稿、更新自己创建或被明确授权接管的草稿、请求人工审核建议，以及读取已发布文章的公开投影与无敏感内链目录；请求审核不改变文章状态。

任何 `status`、`publishedAt`、`scheduledAt`、`indexable`、精选、外部分享、视频 `ownership`、发布/归档/下架字段均必须拒绝为 `403 CONTENT_MCP_SCOPE_DENIED`，不能忽略后静默写入。MCP 不得读取用户邮箱/会话、私密 Work/原图、对象存储键、举报内容、运营备注或审计原始记录；不得代表账号向外部社交平台发布。最小审计仅记录服务身份标识、scope、目标草稿 `publicId`、动作、结果、requestId、时间与拒绝原因类别；不得记录内容全文、Token、凭据或私密用户数据。

## 5. 公共错误语义

| 错误 | 语义 |
| --- | --- |
| `CONTENT_NOT_FOUND` | 公开文章不存在或不满足公开条件 |
| `CONTENT_VERSION_CONFLICT` | 后台编辑版本已变化，需要重新读取 |
| `CONTENT_STATE_INVALID` | 状态流转不允许 |
| `CONTENT_SEO_INVALID` | 发布前 SEO 必填项或 canonical 不符合规则 |
| `CONTENT_MEDIA_INVALID` | 媒体不属于文章边界或格式不允许 |
| `CONTENT_VIDEO_NOT_ALLOWED` | 视频不是品牌自有、平台/频道不在白名单或禁止嵌入 |
| `CONTENT_MCP_SCOPE_DENIED` | MCP 尝试执行非草稿 scope |
| `CONTENT_INPUT_INVALID` | 查询、路径或请求体缺失、格式错误、越界、含未知业务参数，或与当前操作不兼容 |

所有写请求沿用现有 request ID、幂等、trusted Origin/服务身份、限流和审计契约。
