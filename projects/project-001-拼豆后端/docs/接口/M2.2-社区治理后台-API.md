# M2.2 社区治理后台 API 草案

> 状态：M2.2 后端本机已实现；与 `specs/03b-M2.2-社区治理后台-spec.md` 配套。前端管理界面、sitemap/结构化数据和分享按钮尚未联调或上线。

## 1. 查询接口

### `GET /api/v1/admin/community/posts`

支持 `status`、`authorId`、`reportStatus`、`isFeatured`、`from`、`to`、`q`、`cursor`、`limit`。`status` 允许 `published|withdrawn|takedown|deleted`；未传时默认全部状态，不能为了复用访客查询而隐式限制为 `published`。列表返回后台队列所需的帖子摘要、当前状态、举报计数、精选状态，以及派生的 `shareable` / `indexable` 和最近治理摘要；详情内容由单帖接口读取。

### `GET /api/v1/admin/community/posts/:id`

返回一个**完整社区帖子档案**，不使用匿名公开安全投影：

- 帖子完整字段、`published|withdrawn|takedown|deleted` 当前状态、状态时间线、版权确认、复制授权、互动聚合和派生的分享/收录状态；
- 全部仍在保留期内的社区媒体及其角色、说明、状态和受控 Staff/Admin 预览地址；
- 完整 `PublishedPatternVersion` 冻结内容及其版本/规格摘要；
- 作者社区资料摘要、举报摘要、精选/下架/恢复/删除等治理动作与通知结果。

被物理清理的媒体或快照返回 `availability=purged` 与清理审计，不返回伪造的内容。该接口不返回未发布私密 Work/WorkDocument/WorkAsset、私密原图、邮箱、密码、会话、Token、storage key、订单、支付/地址或未经必要授权的举报人身份。

### `GET /api/v1/admin/community/users/:id`

返回作者**完整社区档案**：社区资料、按全部帖子状态统计的发帖概览、帖子归档读取入口、举报/治理摘要、运营备注和特别关注入口，以及该用户填写的全部社交链接。每条社交链接返回真实 `platform`、`url`、`visibility: public|hidden`；后台界面必须在 `hidden` 项旁显示“隐藏”，不得以空值、脱敏值或列表筛选替代。

该接口与关联的社区帖子读取接口共同满足“后台可完整读取社区内容”：它不返回邮箱、未发布的私密 Work/原图、对象存储键、密码、会话、Token、订单、支付/地址或未经必要授权的举报人身份。

后台对社交链接默认只读；链接由用户本人通过认证资料接口维护，Staff/Admin 不能代为修改或切换可见性。

### `GET /api/v1/admin/community/users/:id/posts`

返回该用户全部状态的社区帖子（默认 `published|withdrawn|takedown|deleted`）和治理摘要；支持 `status`、`cursor`、`limit`、`include`。分页只用于性能，不得漏掉任何社区帖子；需要完整媒体/冻结快照/治理动作时，通过 `GET /api/v1/admin/community/posts/:id` 读取。不得扩展到未发布私密作品。

### `GET /api/v1/admin/community/reports`

支持 `status`、`reason`、`postId`、优先级和时间分页。举报人身份默认脱敏。

### `GET /api/v1/admin/community/audit`

本轮未开放独立查询端点。每项写入已存入不可变 `community_moderation_actions`，并随帖子详情返回关联动作；将来若需要跨目标查询或导出，须另行增加权限、保留策略和审计门禁。

## 2. 治理写接口

### `POST /api/v1/admin/community/posts/:id/feature`

请求语义：`{ "featured": true, "reason": "内容完整且适合作为社区示例", "expectedVersion": 4 }`。精选、取消精选均写 `ModerationAction`；系统据 `status=published AND isFeatured=true` 自动派生 SEO/GEO 收录，无独立收录或分享开关。

### `POST /api/v1/admin/community/posts/:id/takedown`

请求语义：`{ "reasonCode": "privacy", "reason": "...", "notifyAuthor": true, "expectedVersion": 4 }`。恢复使用独立的 `POST /api/v1/admin/community/posts/:id/restore`，请求为 `{ "reason": "...", "expectedVersion": 5 }`。下架后公开读接口统一隐藏并清除精选；恢复后重新获得公开分享资格，但不自动恢复精选或 SEO/GEO 收录。

### `POST /api/v1/admin/community/posts/:id/delete`

仅 Admin；需要二次确认字段、理由和幂等键。逻辑删除与物理清理由既有回收策略执行。

### `POST /api/v1/admin/community/reports/:id/resolve`

请求语义：`{ "decision": "resolved|rejected", "reasonCode": "copyright_confirmed|no_violation|insufficient_evidence", "internalNote": "...", "notifyAuthor": true, "notifyReporter": false, "expectedVersion": 1 }`。不把内部备注返回给举报人。

### `POST /api/v1/admin/community/users/:id/notes`

创建内部备注，正文限长，禁止写入密码、Token、完整邮箱和无关敏感推断。返回 `noteId`、时间和过期时间，不返回给用户侧。

### `PATCH /api/v1/admin/community/users/:id/watchlist`

请求语义：`{ "status": "watching|paused|none", "reason": "重复版权举报待复查", "reviewAt": "2026-09-25T00:00:00Z", "expectedVersion": 2 }`。特别关注不是封禁，也不是作者关注。

## 2.1 用户社区资料接口

| 接口 | 权限 | 作用 |
| --- | --- | --- |
| `GET/PATCH /api/v1/community/profile` | 已认证本人 | 读取或更新自己的社区显示名、简介；不返回运营档案。 |
| `PUT/DELETE /api/v1/community/profile/social-links/:platform` | 已认证本人 | 维护自己的白名单社交链接和 `public|hidden`。 |
| `GET /api/v1/community/creators/:id` | 访客 | 只返回资料和 `visibility=public` 链接。 |
| `GET /api/v1/admin/community/media/:id` | Staff/Admin | 受控预览仍在保留期的社区媒体；不返回 `storageKey`。 |

平台仅为 `instagram|tiktok|youtube|pinterest|facebook|x|reddit|linkedin`。URL 必须是对应官方 HTTPS 域名主页链接，不接受短链、查询参数、凭据、跳转器或嵌入代码。后台仅只读用户链接；返回 `visibilityLabel: "隐藏"|"公开"` 供界面明确标注。

## 3. 权限、错误和并发

- 服务端从后台会话读取 Staff/Admin，不接受请求体角色。
- 后台“完整读取”只适用于本 Spec 定义的社区域。隐藏社交链接、已撤回/下架/删除但仍在保留期的社区内容仅在受控 Staff/Admin 响应中返回；不得写入日志、搜索索引、SEO/GEO、MCP、公共缓存或匿名 API。
- 所有写操作要求 trusted Origin、CSRF、防重放/幂等、request ID、速率限制和审计。
- `COMMUNITY_MODERATION_VERSION_CONFLICT` 表示帖子或举报已被其他运营人员更新。
- `COMMUNITY_MODERATION_FORBIDDEN` 表示角色无权执行动作。
- `COMMUNITY_TAKEDOWN_STATE_INVALID` 表示当前状态不支持该转换。
- `COMMUNITY_REPORT_NOT_FOUND`、`COMMUNITY_POST_NOT_FOUND` 统一避免泄露私密对象是否存在。
- `COMMUNITY_FEATURE_BLOCKED_BY_REPORT` / `COMMUNITY_RESTORE_BLOCKED_BY_REPORT` 表示仍有待处理的版权或隐私举报。
- `COMMUNITY_DELETE_CONFIRMATION_REQUIRED` 表示 Admin 删除请求缺少 `confirm: "DELETE"`。
