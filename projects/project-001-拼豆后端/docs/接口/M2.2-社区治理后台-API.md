# M2.2 社区治理后台 API（本地 v1）

> 状态：M2.2 后端本机已实现并经集成测试验证；本文是管理端字段的唯一后端事实来源，与 `specs/03b-M2.2-社区治理后台-spec.md` 配套。前端管理界面、sitemap/结构化数据、公开分享按钮、媒体物理清理调度和真实通知尚未联调或上线。
>
> 本文冻结的是当前实现实际返回的最小安全投影。前端不得把未列出的字段当作存在，也不得把 `null` 当成空字符串、`0` 或“已清理完成”之外的其他状态。

## 0. 通用响应、类型和空值语义

### 0.1 通用响应包装

成功响应在业务字段旁带顶层 `requestId`；错误响应只使用下列结构：

```ts
export type AdminSuccess<T extends object> = T & { requestId: string }

export type AdminErrorResponse = {
  error: {
    code: string
    message: string
    requestId: string
    details: Record<string, unknown>
  }
}
```

所有后台 JSON 响应为 `Cache-Control: no-store`。当前路由把 request ID 放在 JSON 中；不要依赖 `X-Request-Id` 响应头。受控媒体字节路由另有其内容类型和缓存头，不属于上述 JSON 包装。

### 0.2 可复用读取类型

下面的 TypeScript 类型对应当前五类读取端点。`string` 时间均为服务端 ISO-8601 时间字符串；带 `| null` 的字段在数据库没有值时明确返回 JSON `null`。字段未列出即不属于契约。

`document` 是冻结的 `WorkDocument` JSON，不在本文件重复定义；其 v1 真值见 `docs/接口/M1-作品数据契约.md`。本后台只返回已发布快照，不返回未发布私密 Work/WorkDocument/WorkAsset、原图、邮箱、密码、会话、Token、对象存储键、订单、支付、地址或举报人身份。

### 0.3 帖子派生字段

- `shareable` 始终等于 `status === 'published'`。
- `indexable` 始终等于 `status === 'published' && isFeatured === true`。
- `unresolvedHighRiskReportCount` 只统计 `status=pending|reviewing` 且 `reason=copyright|privacy` 的举报。
- 详情没有独立 `statusTimeline` 数组；状态时间信息由 `publishedAt`、`withdrawnAt`、`takedownAt`、`deletedAt` 和 `moderationUpdatedAt` 这些字段表达。

## 1. 查询接口

### 1.1 分页共同规则

五类读取列表（帖子队列、用户帖子、举报队列）都返回 `nextCursor`：有下一页时为非空不透明字符串，没有下一页时为 `null`。默认 `limit=24`；安全整数会被服务端限制到 `1..50`，缺失、空值或非安全整数按 24 处理。`cursor` 是 base64url 编码的 `{ "offset": number }`，客户端不得解析或拼接；无效游标返回 `422 COMMUNITY_MODERATION_INPUT_INVALID`。

这是 offset 分页，不是数据快照：游标不保证跨新增、删除或治理变更时的快照隔离，数据变化时可能出现重复或跳过。服务端取 `limit + 1` 行来判断是否有下一页，并以当前页末尾偏移量生成下一游标。

### 1.2 `GET /api/v1/admin/community/posts`

权限：已登录、已验证、`accountStatus=active` 的 Staff 或 Admin。请求不接受角色字段。

查询参数：

| 参数 | 类型/默认 | 语义 |
| --- | --- | --- |
| `status` | 逗号分隔枚举；默认全部 | `published|withdrawn|takedown|deleted`，重复值会去重；空值按默认全部。 |
| `authorId` | `creator_*` 或省略 | 按社区作者公共 ID 筛选；格式不合法 422。不存在但格式合法时返回空列表。 |
| `reportStatus` | 单个举报状态或省略 | `pending|reviewing|resolved|rejected`；格式不合法 422。 |
| `isFeatured` | `true|false` 或省略 | 精选状态筛选；其他值 422。 |
| `q` | 字符串或省略 | trim 后按标题或标签文本匹配，最多取前 120 个字符；不是独立全文检索。 |
| `cursor` | 不透明字符串 | 见 1.1。 |
| `limit` | 1–50 | 见 1.1。 |

`from`、`to` 当前不是支持参数，传入会被忽略。列表排序固定为 `COALESCE(moderationUpdatedAt, updatedAt) DESC, 数据库内部 id DESC`；内部 id 不出现在响应。返回 `AdminPostListResponse`。

### 1.3 `GET /api/v1/admin/community/posts/:id`

权限同 1.2。返回 `AdminPostDetailResponse`，其中：

- `post` 包含完整社区帖子摘要、`copyrightConfirmed`、`allowCopy`、互动计数、精选信息、媒体、当前冻结发布版本、作者资料、举报摘要和治理动作；
- `media[].status=ready` 时 `availability=available` 并带 `previewUrl`；其他状态返回 `availability=purged` 且不带预览地址。`previewUrl` 是受控后台路由相对路径，不是对象存储 URL；
- `frozenVersion` 有快照时返回完整对象；当前数据库没有关联快照时只返回 `{ availability: 'purged' }`。该字段不承诺物理清理审计，当前实现也未提供媒体/快照清理任务；
- `reports` 不返回 `reporterId` 或 `internalNote`；举报人身份在该版本完全不出响应；
- `moderationActions` 不返回 `requestId`，`actorId` 是内部数字 ID；`beforeState`/`afterState` 是不可进一步假设结构的审计 JSON。

不存在或 ID 格式不合法均统一为 `404 COMMUNITY_POST_NOT_FOUND`。

### 1.4 `GET /api/v1/admin/community/users/:id`

权限同 1.2。路径 ID 是 `creator_*` 公共作者 ID；不存在返回 `404 COMMUNITY_CREATOR_NOT_FOUND`。返回 `AdminCreatorDetailResponse`：

- `creator.socialLinks` 始终返回该作者全部已填写链接；`hidden` 链接保留真实 URL，并带 `visibilityLabel: "隐藏"`；后台不得过滤、置空或自动公开；
- `creator.operations` 是后台运营档案，仅该受控接口返回。`version` 是特别关注档案的并发版本；`notes` 是当前实现完整返回的内部备注列表；
- `postCounts` 统计该作者全部四种帖子状态；`reportSummary.unresolved` 统计 `pending|reviewing` 举报；
- 当前实现没有在该响应内返回治理动作列表或帖子正文，帖子归档需调用 1.5，详情需调用 1.3。

### 1.5 `GET /api/v1/admin/community/users/:id/posts`

权限同 1.2。返回 `AdminCreatorPostsResponse`，帖子字段与 1.2 的 `AdminPostSummary` 相同；默认查询全部四种帖子状态，排序与 1.2 相同。支持 `status`、`cursor`、`limit`，`include` 不是支持参数且会被忽略。格式合法但不存在的 `creator_*` 返回空列表；不得由此接口扩展读取未发布私密作品。完整媒体、冻结文档、举报和治理动作必须另调 1.3。

### 1.6 `GET /api/v1/admin/community/reports`

权限同 1.2。查询参数为 `status`、`reason`、`postId`、`cursor`、`limit`：

- `status` 为单个 `pending|reviewing|resolved|rejected`；
- `reason` 为单个 `copyright|adult_violence|harassment|spam|privacy`；
- `postId` 为 `community_post_*` 公共 ID，格式不合法 422；不存在但格式合法时返回空列表；
- 不支持独立 `priority` 或时间范围参数。

返回 `AdminReportListResponse`。排序固定为：`pending|reviewing` 且理由为 `copyright|privacy` 的记录优先，其余记录按 `createdAt ASC, 数据库内部 id ASC`。列表和详情均不返回举报人身份。

### 1.7 未开放的后台读取

`GET /api/v1/admin/community/audit` 当前未开放；治理写入的不可变动作会随帖子详情返回关联记录。若未来需要跨目标查询或导出，必须另行冻结权限、字段、保留策略和审计门禁。

## 2. 治理写接口

### 2.1 通用写入门槛和幂等

所有下列写接口均要求：Staff/Admin 后台会话、可信 Origin、JSON 请求体、`Idempotency-Key`、请求限流、事务和审计。`Idempotency-Key` 是请求头，不是 JSON 字段；缺失返回 `400 IDEMPOTENCY_KEY_REQUIRED`，格式不是 1–128 个可打印 ASCII 字符返回 `400 IDEMPOTENCY_KEY_INVALID`。

同一操作者、路由和 key 在 24 小时内，若规范化请求体相同，则返回第一次成功结果，不重复写入；同 key 改变请求体返回 `409 IDEMPOTENCY_KEY_REUSED`；相同请求仍在处理中返回 `409 IDEMPOTENCY_REQUEST_IN_PROGRESS`。幂等键不能替代 `expectedVersion`，过期版本仍返回版本冲突。

### 2.2 `expectedVersion` 权威来源

| 写接口 | 请求字段 | 前端读取来源 | 数据库权威字段/初始值 | 成功后 |
| --- | --- | --- | --- | --- |
| 帖子精选、取消精选、下架、恢复、Admin 删除 | `expectedVersion: number`，安全整数且 ≥1 | `AdminPostSummary.moderationVersion` 或 `AdminPostDetailResponse.post.moderationVersion` | `community_posts.moderation_version`，默认 1 | 每次治理变更递增 1；源 Work 进入 `pending_deletion/deleted` 触发公开帖撤回时也会递增。 |
| 举报处理 | `expectedVersion: number`，安全整数且 ≥1 | `AdminReportListItem.version` 或 `AdminPostDetailResponse.post.reports[].version` | `community_reports.version`，默认 1 | 成功处理递增 1。 |
| 特别关注 | `expectedVersion: number`，安全整数且 ≥1 | `AdminCreatorDetailResponse.creator.operations.version` | `community_user_ops_profiles.version`；尚无档案时按 1 处理 | 写入/更新后递增 1。 |
| 运营备注 | 不支持 `expectedVersion` | 无 | 备注表无版本字段 | 只由 `Idempotency-Key` 防重复。 |

服务端在事务中检查权威版本；不匹配统一返回 `409 COMMUNITY_MODERATION_VERSION_CONFLICT`，不得以后写覆盖前写。收到该错误后必须重新读取对应详情/列表再决定是否重试。

### 2.3 帖子精选/取消精选

`POST /api/v1/admin/community/posts/:id/feature`

请求体：

```ts
type FeaturePostRequest = {
  featured: boolean
  reason: string // trim 后 1–1000 字符；精选和取消精选都必填
  expectedVersion: number
}
```

只有当前 `status=published` 才允许操作；设为精选时若有待处理版权/隐私举报，返回 `409 COMMUNITY_FEATURE_BLOCKED_BY_REPORT`。成功响应至少包含 `{ postId, status, isFeatured, moderationVersion, shareable, indexable, requestId }`。

### 2.4 帖子下架与恢复

`POST /api/v1/admin/community/posts/:id/takedown`

```ts
type TakedownPostRequest = {
  reasonCode?: string | null // 缺省按 "other"；非空最多 80 字符
  reason: string // trim 后 1–1000 字符，必填
  notifyAuthor?: boolean // 缺省 false
  expectedVersion: number
}
```

`notifyAuthor=true` 当前只记录 `notificationResult="not_configured"`，不会发送真实通知；`false` 为 `"not_requested"`。仅 `status=published` 可下架，否则 `409 COMMUNITY_TAKEDOWN_STATE_INVALID`。成功状态为 `takedown`，清除精选，`shareable=false`、`indexable=false`。

`POST /api/v1/admin/community/posts/:id/restore`

```ts
type RestorePostRequest = {
  reason: string // trim 后 1–1000 字符，必填
  expectedVersion: number
}
```

仅 `status=takedown` 可恢复；仍有待处理版权/隐私举报时返回 `409 COMMUNITY_RESTORE_BLOCKED_BY_REPORT`。恢复为 `published`，但不自动恢复精选，成功时 `shareable=true`、`indexable=false`。

### 2.5 Admin 删除

`POST /api/v1/admin/community/posts/:id/delete`

仅 Admin。请求体：

```ts
type DeletePostRequest = {
  confirm: 'DELETE' // 必须精确等于大写 DELETE
  reason: string // trim 后 1–1000 字符，必填
  expectedVersion: number
}
```

缺少或不匹配确认字段返回 `422 COMMUNITY_DELETE_CONFIRMATION_REQUIRED`；Staff 或普通用户返回 `403 COMMUNITY_MODERATION_FORBIDDEN`。当前实现把帖子改为 `deleted`、清除精选并递增 `moderationVersion`；这是逻辑删除，物理媒体/快照清理不在本接口内，也没有可供前端依赖的清理时间或恢复承诺。成功响应为 `{ postId, status: 'deleted', isFeatured: false, moderationVersion, shareable: false, indexable: false, requestId }`。

### 2.6 举报处理

`POST /api/v1/admin/community/reports/:id/resolve`

```ts
type ResolveReportRequest = {
  decision: 'resolved' | 'rejected'
  reasonCode: string // trim 后 1–80 字符；当前实现不限制为固定枚举
  internalNote?: string | null // trim 后最多 2000 字符；缺省/null 均表示无内部说明
  notifyAuthor?: boolean // 缺省 false
  notifyReporter?: boolean // 缺省 false
  expectedVersion: number
}
```

`notifyAuthor`/`notifyReporter` 当前不发送通知，结果按 `作者结果/举报人结果` 拼接为 `not_configured` 或 `not_requested`。已是 `resolved|rejected` 的举报返回 `409 COMMUNITY_REPORT_STATE_INVALID`；成功响应包含 `reportId`、新的 `status`、新的 `version`、`notificationResult` 和 `requestId`。`internalNote` 只存运营侧，不进入用户侧响应。

### 2.7 运营备注

`POST /api/v1/admin/community/users/:id/notes`

```ts
type CreateNoteRequest = {
  body: string // trim 后 1–2000 字符，必填
  tags?: string[] // 缺省 []；最多 10 个，每个 trim 后 1–32 字符
  expiresAt?: string | null // ISO 时间；缺省为服务端当前时间 + 180 天
}

type CreateNoteResponse = AdminSuccess<{
  note: { noteId: string; expiresAt: string; createdAt: string }
}>
```

备注不得写入密码、Token、完整邮箱或与治理无关的敏感推断。该接口没有 `expectedVersion`；仍必须携带 `Idempotency-Key`。由于 `expiresAt` 缺省值是在请求解析时生成，若要让重试稳定命中同一个幂等请求，客户端应显式传入同一个 `expiresAt`。备注只在后台安全投影中可见，不返回给用户侧、公开页面、SEO/GEO 或 MCP。

### 2.8 特别关注

`PATCH /api/v1/admin/community/users/:id/watchlist`

```ts
type WatchlistRequest = {
  status: 'watching' | 'paused' | 'none'
  reason?: string | null // watching/paused 必填；none 可省略；最多 1000 字符
  reviewAt?: string | null // watching/paused 必填，必须是未来 ISO 时间；none 时为 null
  expectedVersion: number
}
```

成功响应为 `{ watchlist: { status, reason, ownerStaffId, reviewAt, version, updatedAt }, requestId }`。特别关注不是封禁，也不是作者关注；`status=none` 会清除负责人和复查时间。

## 3. 社区资料与受控媒体补充接口

| 接口 | 权限 | 契约 |
| --- | --- | --- |
| `GET/PATCH /api/v1/community/profile` | 已认证本人 | 读取/更新自己的 `displayName`、`bio`；不返回运营档案。 |
| `PUT/DELETE /api/v1/community/profile/social-links/:platform` | 已认证本人 | 维护白名单平台和 `public|hidden`；后台只读，不代替用户修改。 |
| `GET /api/v1/community/creators/:id` | 访客 | 只返回 `visibility=public` 链接。 |
| `GET /api/v1/admin/community/media/:id` | Staff/Admin | 受控读取 `ready` 社区媒体字节，不返回 `storageKey`；不存在、已删除或对象已清理均为 404。 |

平台固定为 `instagram|tiktok|youtube|pinterest|facebook|x|reddit|linkedin`；URL 必须对应官方 HTTPS 域名主页，不接受短链、查询参数、凭据、跳转器或嵌入代码。后台作者详情显示全部链接及 `visibilityLabel: "隐藏"|"公开"`，访客作者页只显示公开项。

## 4. 权限、错误和并发

### 4.1 权限

- 后台五类读取端点和全部治理写端点只接受服务端会话中的 active Staff/Admin；角色不从请求体读取。
- 普通用户、未登录、未验证、停用账号和非后台角色不能通过这些端点读取或写入社区治理数据。
- 写入还必须通过 trusted Origin、CSRF/请求防重放、幂等、限流、事务和审计；读取不要求写入 Origin，但浏览器跨域消费仍受后端 CORS 白名单限制。
- 隐藏社交链接和非 published 社区内容只在受控后台响应中出现；不得写入公开缓存、日志、搜索、SEO/GEO、MCP 或匿名 API。

### 4.2 错误结构与主要错误码

HTTP 错误统一使用 0.1 的 `AdminErrorResponse`。主要错误如下：

| HTTP | code | 触发条件 |
| --- | --- | --- |
| 400 | `IDEMPOTENCY_KEY_REQUIRED` / `IDEMPOTENCY_KEY_INVALID` / `REQUEST_INVALID` | 写请求缺少/格式错误幂等键、请求不是有效 JSON 等。 |
| 401 | `AUTH_REQUIRED` | 无有效登录会话。 |
| 403 | `ACCOUNT_UNAVAILABLE` / `COMMUNITY_MODERATION_FORBIDDEN` / `ORIGIN_NOT_ALLOWED` | 账号不可用、非 Staff/Admin、Admin 删除越权或写请求来源不可信。 |
| 404 | `COMMUNITY_POST_NOT_FOUND` / `COMMUNITY_CREATOR_NOT_FOUND` / `COMMUNITY_REPORT_NOT_FOUND` / `COMMUNITY_MEDIA_NOT_FOUND` | ID 不存在或不满足公共 ID 格式；不泄露私密对象存在性。 |
| 409 | `COMMUNITY_MODERATION_VERSION_CONFLICT` / `COMMUNITY_REPORT_STATE_INVALID` / `COMMUNITY_TAKEDOWN_STATE_INVALID` / `COMMUNITY_FEATURE_STATE_INVALID` / `COMMUNITY_FEATURE_BLOCKED_BY_REPORT` / `COMMUNITY_RESTORE_BLOCKED_BY_REPORT` / `IDEMPOTENCY_KEY_REUSED` / `IDEMPOTENCY_REQUEST_IN_PROGRESS` | 版本过期、状态转换不允许、举报阻止治理或幂等冲突。 |
| 415 | `REQUEST_INVALID` | 写请求 Content-Type 不是 `application/json`。 |
| 422 | `COMMUNITY_MODERATION_INPUT_INVALID` / `COMMUNITY_DELETE_CONFIRMATION_REQUIRED` | 查询/请求字段、游标、理由或确认字段不符合当前实现。 |
| 429 | `RATE_LIMITED` | 后台读取或写入超过已配置的认证用户限流。 |
| 503 | `COMMUNITY_MEDIA_STORAGE_UNAVAILABLE` | 后台媒体对象存储暂不可用。 |
| 500 | `INTERNAL_ERROR` / `TRANSACTION_UNAVAILABLE` | 服务端内部或事务不可用；前端不得据此猜测数据是否已写入。 |

`details` 当前默认为空对象；除非后端未来显式增加字段，前端不要依赖其中存在具体属性。治理版本冲突和状态错误都不会自动重试或静默刷新。

## 5. 当前未冻结/未实现项

- 没有独立审计查询/导出端点；详情动作列表不是完整审计导出 API。
- 没有媒体/冻结快照物理清理调度、清理时间线或从清理备份恢复的能力；`availability=purged` 只是当前安全投影。
- `notifyAuthor`、`notifyReporter` 只记录 `not_configured`/`not_requested`，没有真实邮件或站内通知。
- 公开 sitemap、结构化数据、分享按钮、SEO/GEO 页面、官方内容发布和前端管理后台真实字段展示不属于本契约已完成范围。
